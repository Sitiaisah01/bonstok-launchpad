Bonstok Token (BSTK)

Bonstok is a small community token issued on the Ammora protocol's segmented bonding curve. It was created with a self-built TypeScript implementation of the Ammora SDK: a dedicated team config, the token launch, and the first buy were executed atomically on GIWA Sepolia — no graduation, the curve simply trades.
